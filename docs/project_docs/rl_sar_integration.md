## 4. 해석
- 직진은 목표(비율 ≥0.7, 방향 ≤15°) 충족. 최소 유효 속도 약 0.17 m/s (명령 0.2). 2회 측정에서 재현.
- **걸으면서 도는 경우**는 wz 0.2부터 정상 추종 (좌 0.97~0.99, 우 0.79~0.84), 전진 속도도 0.79~1.00 유지. 즉 작은 명령 무반응 구간은 "제자리에서 돌 때"와 "저속 직진/후진"에만 해당.
- 정책에 작은 명령 무반응 구간이 있음: 직진 명령 0.1 이하, 후진 0.2 이하, 제자리 회전 0.5 rad/s 이하. rl_sar 코드에는 데드밴드 처리가 없음(소스 grep으로 확인) → 정책 자체 성질. 원인(학습 시 작은 명령 제거 등)은 미확인.
- 후진은 −0.4 이상에서 0.74~0.80, −0.3은 0.6 안팎.
- 제자리 회전은 명령 0.8 이상에서 동작(최소 실제 yaw속도 좌 약 0.59, 우 약 0.45 rad/s). 우회전이 좌회전보다 약함: 제자리 0.56~0.67 vs 0.73~0.95, 복합 0.79~0.84 vs 0.97~0.99. 두 시험에서 모두 나타나 재현되는 비대칭으로 봄. 원인은 미확인.
