# 진단 A (diag6) 결과: 다리별 접지/하중/위상 (2026-11-04 저녁)

bigexp_p6_results.md의 후속. 그 문서의 "다음 후보 A"는 이 문서의 실행 결과로 대체된다. 조건: p340, km1, h0.20, cx {0, -0.060, -0.065, -0.070, -0.075}, walk/back 각 10초, 정상상태 3~10초 구간, 약 218 Hz 기록(관절 위치, 명령, 자세). cx -0.075는 시뮬 기동 실패("ground_truth 없음")로 결과 없음.

## 스크립트 쪽 문제와 수정 (결과 해석 전에 알아둘 것)
- 1차 시도 실패: joint_states effort 필드 전부 NaN(a1.urdf.xacro의 state_interface는 position, velocity뿐), 시각을 콜백 처리 시점의 now()로 재서 표본이 10 Hz.
- 2차 시도 5개 중 3개 결과 없음: 원인은 기록 스레드가 도는 중에 리스트를 배열로 바꾸는 경쟁 상태(로그: "boolean index did not match ... 5922 vs 5921"). 수정판(fix_diag6b.py, diag6.py 500줄, md5 7d78a076...)에서 해결, 3차 실행에서 4/5 성공.
- 토크는 PD 명령 기반 추정: tau = p*(q_cmd - q) - d*qdot, 서 있을 때 네 다리 합력이 체중(136 N)이 되도록 배율 k 하나로 보정. 3차 실행 k = 0.283 / 0.286 / 0.381 / 0.286 (공칭 대비 약 1/3.5). 사전 기준(0.5~2)을 벗어났지만, JTC가 1/60 s 보간 궤적의 일부만 따라가는 구조(명령이 5 ms마다 갱신되면 오차의 일부만 PD에 반영)로 설명 가능하다고 보며 3개 조건에서 일정. 절대값이 아니라 다리 간 비율과 조건 간 변화를 보는 용도로만 쓸 것.
- 검증: 서 있을 때 앞다리 하중 비율 = cx 0 -> 0.44, -0.060 -> 0.63, -0.065 -> 0.60, -0.070 -> 0.66. 기하 예측(발 1 cm 이동 = 휠베이스 0.361 m 대비 약 2.8 %p)은 7 cm에 약 19 %p, 관측 22 %p. 정지 하중 분배는 기하와 대략 일치. 앞뒤 하중이 균형(앞 50%)인 cx는 약 -0.02 ~ -0.03 (이전 최고 설정 cx -0.03 부근).
- 동적 힘(Fx, 걷는 중 Fz 첨두 190~270 N)은 신뢰 낮음. ΣFx는 정지 기준선을 빼지 않았고, 후진에서도 부호가 바뀌지 않으므로 해석하지 말 것.

## 다리별 관찰 (walk)
- **cx 0: 한쪽 대각 쌍이 안 든다.** FR, RL 접지 비율 1.00, 접지 횟수 0, 발 높이 95퍼센타일 1.4~1.6 cm(명령 4 cm). FL, RR만 걷고(발 높이 약 2 cm) 이 다리들은 접지 때와 이륙 때 몸 기준 x가 같다(FL 0.188 vs 0.189, RR -0.172 vs -0.172): 계획된 스탠스 훑기가 실현되지 않음. back에서도 FR은 안 든다(RL은 접지 42회로 떨림).
- **cx -0.060 ~ -0.065: 네 다리 모두 들지만 얕다** (발 높이 1.4~3.4 cm). 위상(FL 대비): FR 0.56, RL 0.39 (트롯이면 0.5), RR 0.94~0.96 (0이면 정상). RL이 모든 조건에서 0.38~0.39로 일관되게 앞섬.
- **cx -0.070: 체제 전환.** 뒷다리 발 높이 3.9, 4.5 cm(명령 4 cm 도달), RR 접지 비율 0.40, 앞다리 접지 횟수 FL 28/FR 21(정상 14; 한 주기에 두 번 닿는 떨림), RR 위상 0.74로 트롯에서 이탈, 몸통 코 숙임 2.9도. 후진은 RR 발 높이 7.1 cm(튐), 요 -18 deg/s.
- **걷는 동안 대각 쌍 하중이 한쪽(FR+RL)에 치우친다**: walk에서 FR+RL이 전체의 61, 64, 66, 61 % (cx 0, -0.060, -0.065, -0.070), back에서 62, 65, 64, 57 %. 서 있을 때는 50~52 %. 전진/후진 모두 같은 쌍이 무거움. RR이 가장 가볍다 (-0.060 이하에서 12~17 N, 서 있을 때 약 23~26 N). 이 하중은 PD 추정이라 신뢰 중간: 접지 비율(cx 0에서 FR, RL 1.00)과는 방향이 일치하지만 cx -0.065, -0.070에서는 접지 비율이 일관되지 않음.
- 해석 후보: 명령은 두 대각 쌍에 대칭인데 실제로는 한 쌍(FL+RR)만 걷고 다른 쌍(FR+RL)은 끌리는 대칭 깨짐. 이 쌍 비대칭이 시작 위상/명령 계단 입력에서 생기는지(다중 안정성), 플랜트 비대칭인지는 미확인. 전환(-0.070)은 뒷다리 하중 비율이 약 34% 이하로 내려갈 때 뒷다리가 가볍게 튀는 패턴과 일치하나 하중 문턱이라는 단정은 못 함(-0.060 -> -0.065 사이에 앞 하중 비율이 거의 불변인데 속도는 0.032 -> 0.051).
- 발 높이는 몸 자세(피치)와 정지 기준 높이에 의존. 접지 기준은 정지 시 발 중심 높이 + 1.0 cm(진입)/1.8 cm(이탈).
