# A1 보행 튜닝 실험 로그 (2026-11-03~04, WSL2)

기준 환경: ROS 2 Humble + Gazebo Classic 11, CHAMP + gazebo_ros2_control(effort + JTC PD), 평지 gait_test.world. 시험: walk(vx 0.2), back(vx -0.2), spin_left/right(wz ±0.5). walk/back 열은 전진비.

현재 채택 상태: update_rate 1000, p 360, d 0.9, mu 0.6, swing 0.04, stance 0.25, nominal 0.2, com_x 0.0. 월드 파일은 gait_test.world.orig 로 원복할 것(iters 200은 효과 없음).

## 속도 응답 곡선 (foot_trace, 8초, 2026-11-04)
| 명령 vx | 실제 몸통 속도 |
|---|---|
| +0.1 | +0.002 |
| +0.2 | +0.042 (이전 측정) |
| +0.3 | +0.064 |
| +0.4 | +0.064 |
| -0.1 | -0.144 (명령보다 큼) |
| -0.2 | -0.192 |
| -0.3 | -0.287 |
| -0.4 | -0.327 |
- 전진: 0.1에서 거의 0(불감대), 0.3 이후 약 0.064 m/s에서 포화. 후진: 0.3까지 거의 선형, 0.4에서 약 0.33으로 포화, -0.1에서는 오히려 초과.
- 해석: 전진은 일정 비율 손실이 아니라 "불감대 + 낮은 상한(약 0.06 m/s)"이라 명령을 키워 보내는 보정으로 해결 불가. 후진 쪽으로 치우친 순 추진 편향(약 -0.05~-0.07 m/s)이 있을 가능성(vx=0 드리프트로 확인 예정).

## 스윕 요약 (SW1, SW2, 화면 없음, 총 34조합)
- walk 최고 0.32. 점수 잔차 sd 0.11~0.12, 단일 조합 간 0.2 미만 차이는 의미 없음. d는 최적이 약 1~2 근처, nominal 0.19가 0.23보다 경계 수준으로 좋음. 나머지는 잡음 범위.
- 결론: 다룬 변수들은 전진/후진 비대칭의 원인이 아님.

## 발 추적 진단 (foot_trace.py, foot_cycle.py, foot_phase.py)
- 눈 관찰: 스윙 중 발 끌림 없음.
- 걸음 주기 0.50 s, 트롯 위상 전진/후진 동일. 발 앞뒤 폭 전진 4.7~6.1 cm, 후진 4.4~6.6 cm: CHAMP 명령 보폭이 양방향 동일하게 실행됨.
- 몸 기준 발 들림(z 폭): 전진 1.6~2.2 cm, 후진 1.8~4.1 cm (명령 4 cm).
- 높이-앞뒤속도 맞물림(이상 +1): 전진 지연0 평균 0.15, 후진 0.31. 약한 차이.
- 한계: ground_truth 갱신이 tf보다 느려 월드 좌표 속도 신뢰 낮음.

## 접촉/월드 점검 (xacro, world)
- 발 충돌 구 반지름 0.02(시각 0.01), 질량 0.06. 발 mu 0.6, 다른 링크 0.2, 전 링크 kp 1e6 kd 1.0 (ERP~0.999로 사실상 딱딱함, 체중 침투 약 0.07 mm). minDepth/maxVel/slip/fdir1 미설정(기본값).
- 월드: 간격 0.001, 1000 Hz, 솔버 설정 없음(기본 iters 50). 바닥 mu 100/mu2 50.
- 다리 말랑함 추정(링크 20 cm, p 360): 발 컴플라이언스 0.07~0.14 mm/N, 체중 하중 시 몇 mm. 주원인 아님. 따라서 "걸을 때 발 z가 4~16 mm 낮다"는 접촉 연성 때문이 아니라 측정 잡음/몸 출렁임으로 해석.
