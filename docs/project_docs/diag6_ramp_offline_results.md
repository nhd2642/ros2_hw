# 오프라인 분석 + 시작 램프 시험 결과 (2026-11-04 저녁)

diag6_results.md의 "다음 계획" 1번(오프라인 분석)과 2번(시작 램프 시험)을 실행한 결과. 그 문서의 해석 후보 "쌍 비대칭이 시작 위상/명령 계단에서 생기는 다중 안정성" 은 아래 결과로 기각된다. 스크립트: diag6_off.py(107줄, md5 1b5555ff...), fix_diag6c.py(56줄, md5 948ddad5...), 패치된 diag6.py(511줄, md5 9c4ef43d...). 조건: p340, km1, h0.20, 램프는 속도 명령을 0에서 0.2까지 3초 직선으로 올리고 시험 시간을 3초 늘림(정상상태 구간 길이는 7초로 동일). 정상상태 수치는 시작 후 3~10 s(계단) / 6~13 s(램프) 구간.

## 1. 램프 대 계단: 효과 없음
| cx | walk v_path 계단 -> 램프 (m/s) | back v_path 계단 -> 램프 | walk yaw (deg/s) |
|---|---|---|---|
| 0 | 0.042 -> 0.041 | -0.196 -> -0.195 | -1.3 -> -1.4 |
| -0.03 | 0.048 -> 0.044 | -0.173 -> -0.190 | -0.6 -> -0.9 |
| -0.060 | 0.032 -> 0.032 | -0.176 -> -0.170 | +1.8 -> +0.7 |
- 걷기 정상상태 속도는 변하지 않았고, FR+RL 대각 쌍 하중 비율(0.60~0.66)과 다리별 발 들림 패턴도 거의 같다(cx 0 walk 정상상태 발 들림 cm, FL/FR/RL/RR: 계단 2.1/1.5/1.7/2.0, 램프 2.2/1.4/1.2/1.7).
- 계단 시작에서만 처음 1~2초 동안 빠른 구간이 있다(cx -0.065 walk 0.086~0.118 -> 0.036, cx -0.060 0.076 -> 0.03). 램프에는 없다. P6의 10초 평균이 정상상태보다 높은 이유가 이것. 정상상태 수치는 영향 없음.
- 결론: 시작 충격/계단 입력/다중 안정성은 원인이 아니다. 같은 정상상태로 수렴한다.

## 2. 시간 경과 (계단/램프 공통)
- 첫 걸음 몇 주기 안에는 다리가 명령 높이 근처로 든다(램프 -0.060 첫 1초: 2.3/2.3/3.3/4.6 cm). 1~2초(2~4주기) 지나며 정상상태 값으로 줄어든다(RR 4.6 -> 2.5). 줄어드는 원인은 미확인. 적분 항(i 0.2, 클램프 2.5)으로 설명하기엔 오차 x 시간이 너무 작아 가능성 낮다고 봄(계산만, 측정 안 함).
- cx 0 램프 walk 8~9초에 발 들림이 잠깐 커지는 사건이 한 번 있었음(원인 미상, 속도 0.030으로 약간 감소).

## 3. 명령 대비 실제 발 궤적 (정상상태, 몸 기준)
za/zc = 발 높이 진폭 실제/명령(명령 3.7~4.1 cm), xa/xc = 앞뒤 진폭 실제/명령.
| cx | 방향 | za/zc FL/FR/RL/RR | xa/xc 범위 | 속도비 |
|---|---|---|---|---|
| 0 | walk | 0.65/0.64/0.59/0.42 | 1.10~1.54 | 0.21 |
| 0 | back | 0.83/0.76/1.22/0.44 | 1.05~1.36 | 0.98 |
| -0.03 | walk | 0.61/0.54/0.35/0.66 | 1.06~1.10 | 0.24 |
| -0.03 | back | 0.97/1.13/1.24/1.07 | 1.09~1.49 | 0.87 |
| -0.060 | walk | 0.90/0.94/0.77/0.89 | 1.10~1.17 | 0.16 |
| -0.060 | back | 1.02/0.89/0.93/0.83 | 1.14~1.48 | 0.88 |
| -0.065 | walk | 0.93/0.96/0.83/0.89 | 1.11~1.25 | 0.26 |
| -0.070 | walk | 1.30/0.99/0.79/0.99 | 1.06~1.15 | 0.64 |
- 앞뒤(x) 훑기는 모든 조건에서 명령 이상(1.05~1.5)으로 실행된다. 즉 발 궤적의 x 성분은 PD가 잘 따른다.
- 수직(z) 들림은 cx 0 ~ -0.03에서 걷기 때 명령의 35~66 %로 줄고 후진에서는 줄지 않는다(-0.03: walk 0.35~0.66, back 0.97~1.24). 그러나 cx -0.060에서는 walk/back 들림 비율이 같은데(0.77~0.94 대 0.83~1.02) 속도는 0.16 대 0.88로 갈린다.
- 따라서 **수직 들림 추종 손실은 전진/후진 속도 비대칭의 원인이 아니다**(cx -0.060이 반례). cx -0.065 walk는 들림이 거의 다 실행(0.83~0.96)되는데도 0.26배, cx -0.070 walk는 들림 비율이 1.0 근처이고 0.64배라서 속도와 들림 비율의 관계도 일관되지 않는다(5개 조건, 단조 아님).
- 지연(cx -0.03 이하 walk/back): 앞다리 20~50 ms, 뒷다리 5~10 ms 정도(cx 0 walk는 FL 10 / FR 5 / RL 65 / RR 20 ms로 양상이 다름). RL은 후진에서 -35~-100 ms(실제가 명령을 앞섬; 접지 횟수 25~42회로 떨림이 있어 상관 지연 해석이 모호). 처짐(평균 발 높이 실제-명령) FR 11~14 mm, RL 9~20 mm로 큼.

## 4. 이번에 정리된 것
- 기각: 시작 충격/계단 입력, 시작 위상 다중 안정성, 수직 들림 추종 손실(전진/후진 비대칭의 원인으로서).
- 남은 사실: 명령 궤적(x 훑기, z 들림)은 두 방향에서 비슷한 정도로 실행되는데 지면 속도는 전진 0.03~0.05 대 후진 0.17~0.20 m/s로 5배 가량 갈린다. 손실은 발-지면 상호작용(힘 전달, 미끄러짐) 단계에서 일어난다고 볼 수밖에 없으나 **실제 접촉력은 한 번도 측정하지 못했다**. 지금까지의 하중/힘은 PD 추정이고 ΣFx 등 동적 힘은 부호가 후진에서도 안 바뀌어 해석 불가(diag6_results.md 참고).
- 못 한 것: Gazebo 접촉 센서(발 4개, URDF에 bumper 플러그인)로 실제 Fx/Fz 측정. gait_experiment_log.md의 "남음" 목록에 있던 항목이며 아직 남아 있다. 동역학을 바꾸지 않는 계측이라 단일 변수 원칙은 지켜진다.
