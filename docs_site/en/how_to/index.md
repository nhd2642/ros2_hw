# How-To Guides

How-To guides are short pages on **how to get one specific thing done**. Background lives in {doc}`../concepts/index`.

| Guide | Use it when |
| --- | --- |
| {doc}`run_unit_tests` | you changed code and want to check the logic before starting the sim |
| {doc}`teleop` | you want to drive an A1 from the keyboard |
| {doc}`diagnostics` | SLAM, Nav2, lidar or terrain looks wrong and you want to find out why |
| {doc}`measure_gait` | you changed the gait config and want to measure speed response and tilt |
| {doc}`tune_parameters` | you want to change speeds, thresholds or time limits |
| {doc}`troubleshooting` | something doesn't work |
