# mission.yaml

Location: `disaster_sim/config/mission.yaml`. **It is generated by `make_world.py`; don't edit it by hand.** Coordinates are Gazebo world meters.

## Full file

```yaml
spawn:                       # start pose [x, y, yaw]
  husky: [0.0, 0.0, 0.0]
  a1_1: [-2.4, -0.8, 0.0]
  a1_2: [-2.4, 0.8, 0.0]
slots:                       # follow slot relative to the Husky [back(-)/front(+), right(-)/left(+)]
  a1_1: [-1.6, -0.8]
  a1_2: [-1.6, 0.8]
sets:                        # mission order
- name: set1
  park: [9.6, 0.0]           # Husky parking spot
  zones:                     # per-robot exploration zone [x_min, x_max, y_min, y_max]
    a1_2: [4.0, 12.0, 1.5, 6.5]
    a1_1: [4.0, 12.0, -6.5, -1.5]
  people: 2                  # people in this set (for the "not found" note)
- name: set2
  park: [21.6, 0.0]
  zones: {a1_2: [16.0, 24.0, 1.5, 6.5], a1_1: [16.0, 24.0, -6.5, -1.5]}
  people: 2
- name: set3
  park: [33.6, 0.0]

- name: common

  people: 3
people_truth:                # true person positions for evaluation (only mission_watch reads these)

- [10.5, -6.1]
- [16.4, 2.9]
- [17.0, -6.1]

- [52.6, -4.6]
```

## Keys

| Key | Read by | Meaning |
| --- | --- | --- |
| `spawn` | sim.launch.py, mission.launch.py (`start_poses`) | start poses for set 0 |
| `slots` | a1_follower, husky_mission, `start_poses` | follow slots. With `start_set` ≥ 1 the A1s spawn in these slots relative to the previous parking spot |
| `sets[].name` | husky_mission, `/mission/state` | set name |
| `sets[].park` | husky_mission → `/husky/goal` | Husky parking spot |
| `sets[].zones` | husky_mission → `/mission/state` | per-robot exploration zone |
| `sets[].people` | husky_mission | configured person count. Fewer found → "n not found" |
| `people_truth` | mission_watch.py | evaluation truth (robot nodes don't read it) |

`start_poses(cfg, k)` (`comm_relay/mission_logic.py`) computes spawn poses for a `start_set`: for k = 0 it is `spawn`; for k ≥ 1 the Husky is at `sets[k-1].park` and the A1s are in their `slots` relative to it.
